# Smart IP Planner

Локальное и облачное (Streamlit Community Cloud) веб-приложение для автоматического планирования, распределения и диагностики IPv4-адресного пространства компьютерной сети.

**Тема:** «Компьютерлік желідегі IP-адрестерді автоматты жоспарлау және бөлу құралын жасау»

## Деплой на Streamlit Community Cloud (без нагрузки на MacBook)

1. Распакуйте архив и загрузите папку `smart_ip_planner` в публичный или приватный репозиторий GitHub.
2. Перейдите на [share.streamlit.io](https://share.streamlit.io) → **Create app** → выберите ваш репозиторий.
3. Укажите **Main file path**: `streamlit_app.py` (если загрузили содержимое папки в корень репозитория) или `smart_ip_planner/streamlit_app.py`.
4. Нажмите **Deploy**. Приложение автоматически установит зависимости из `requirements.txt`, создаст SQLite-базу и загрузит 3 встроенных демо-проекта.

## Локальный запуск (macOS / Windows / Linux)

```bash
cd smart_ip_planner
python3 -m venv .venv
source .venv/bin/activate        # macOS / Linux
# .venv\Scripts\activate         # Windows

pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Запуск автотестов

```bash
pytest -v
```

## Структура проекта

- `streamlit_app.py` — точка входа Streamlit-приложения (5 вкладок: Планирование, Аналитика, Диагностика, Автоисправления и рост, Экспорт и Cisco).
- `core/` — независимое алгоритмическое ядро (целочисленные расчёты VLSM/FLSM, подготовка свободного пространства, метрики, правила NET-001…NET-010, сценарии A/B, моделирование роста, генератор Cisco IOS, 3 демо-проекта).
- `storage/` — SQLite-репозиторий проектов (с автовыбором доступного пути для облака и локального ПК), импорт/экспорт JSON, экспорт Excel (4 листа) и CSV.
- `i18n/` — полная локализация на казахский язык (по умолчанию, ФТ-28) + переключатель на русский (ФТ-30).
- `ui/` — графики Plotly (карта адресного пространства, устройства и ёмкость, сравнение VLSM/FLSM) и стили.
- `tests/` — модульные и интеграционные тесты (`pytest`).
